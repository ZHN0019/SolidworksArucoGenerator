# Security Policy

## Supported Version

Security fixes are currently applied to the latest published version.

| Version | Supported |
|---|---|
| 1.1.x | Yes |
| 1.0.x | No |

## Reporting a Vulnerability

Open a GitHub issue containing only the minimum information needed to
reproduce the problem. Do not include passwords, access tokens, private
models, proprietary CAD data, or other confidential information.

For a vulnerability that cannot be disclosed safely in a public issue, use
GitHub's private vulnerability reporting feature when it is enabled for this
repository.
